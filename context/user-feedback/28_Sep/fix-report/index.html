ผลที่ผู้ทดสอบเจอ (28/09/2026)

บันทึกผลประเมินรอบล่าสุดเป็น ไม่เหมาะสม แล้วกด ไม่เหมาะสม — เลือกใหม่ กด ถัดไป และบันทึกเข้าพัก ระบบไม่กลับไปเลือกสถานที่ และไปขั้นที่ 4 เริ่มปฏิบัติ (ACTIVE) ได้

ผลที่ควรได้: ระบบต้องกลับไปเลือกสถานที่ใหม่ (WIT0824) และเริ่มปฏิบัติไม่ได้

หลังแก้ไข

เมื่อกด ไม่เหมาะสม — เลือกใหม่ ระบบพากลับไปขั้นเสนอสถานที่ใหม่ทันที หากพยายามไปขั้นเริ่มปฏิบัติ จะมีข้อความแจ้งว่าผลประเมินรอบล่าสุดไม่เหมาะสม ต้องกลับไปเสนอสถานที่ใหม่และประเมินให้ผ่านก่อน และกดเริ่มปฏิบัติแล้วก็ไม่เป็น ACTIVE เมื่อเสนอสถานที่ใหม่และประเมินว่า เหมาะสม จึงเริ่มปฏิบัติได้
