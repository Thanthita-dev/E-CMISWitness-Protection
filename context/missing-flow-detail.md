# รายละเอียด flow ที่ยังขาด — อ่านคู่กับผัง User Flow

ไฟล์นี้ไล่ตามลำดับ sheet ในผัง `User_Flow_Activity_6_Redesign_v5_A4_Tab_02.drawio`
แสดง **เฉพาะจุดที่ยังขาดหรือทำงานไม่ตรงผัง** — จุดที่ทำได้ครบแล้วไม่ถูกนำมาแสดง
สรุปเชิงโครงสร้างและแผนงานอยู่ที่ [gap-analysis-reject-flow.md](gap-analysis-reject-flow.md)

**วิธีอ่าน:** เปิดผังที่ sheet เดียวกัน แล้วหา node ตาม code ที่หัวการ์ด
แต่ละการ์ดบอก 4 อย่าง — ผังบอกให้ทำอะไร · ตอนนี้ระบบทำอะไร · ต่างกันตรงไหน · ถ้าไม่แก้จะเจอปัญหาอะไร

| ป้ายสถานะ | ความหมาย |
|---|---|
| 🔴 ไม่มีเลย | กดไม่ได้ ไม่มีหน้าจอ ไม่มีการบันทึก |
| 🟠 กดได้แต่ไม่เกิดผล | มีปุ่ม/ช่องกรอก แต่กดแล้วสถานะงานไม่เปลี่ยน |
| 🟡 ทำงานผิดทาง | ทำได้ แต่งานวิ่งไปคนละทางกับผัง |

> **อัปเดตล่าสุด:** ไล่เทียบผังกับ code ครบทุก sheet (227 node) แล้ว
> · Sheet 05 ปิดครบ — WIT0510 / WIT0511 แก้แล้ว ย้ายไปภาคผนวก

>   การคุ้มครองชั่วคราวจึงเกิดขึ้นได้จากการใช้งานจริง ไม่ต้องพึ่งข้อมูลตั้งต้นอีกต่อไป
> · **Sheet 07 ปิดครบแล้ว** — WIT0708 / WIT0709 / WIT0713 แก้แล้ว ย้ายไปภาคผนวก
>   ผลพิจารณาครบ 4 แขนงตาม WIT0704 · เคสที่ถูกส่งกลับเดินต่อได้จริง · 08C มีทางเข้าครบทั้งสองทาง

> · **Sheet 09A ปิดครบแล้ว** — WIT0904 / WIT0905 / WIT0909 แก้แล้ว ย้ายไปภาคผนวก
>   ร่าง คบ.10 ข้ามด่านกลั่นกรองไปถึงผู้ลงนามไม่ได้อีกต่อไป · เคสไม่อนุมัติปิดเรื่องได้จริงเมื่อพ้น 30 วัน
> · **Sheet 09B ปิดครบแล้ว** — WIT0914 ถึง WIT0921 แก้แล้ว ย้ายไปภาคผนวก

> · **Sheet 11A ปิดครบแล้ว** — WIT1110 แก้แล้ว ย้ายไปภาคผนวก

> · **ไล่ครบทุก sheet แล้วไม่มีจุดค้างเหลือ** — ทุก node ในผังเดินได้จริงด้วยการกด
