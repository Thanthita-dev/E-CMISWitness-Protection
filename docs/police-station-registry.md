# ทะเบียนสถานีตำรวจสำหรับประสานวิธีที่ 4

สถานะ: **ยังไม่ครบทั่วประเทศ** ข้อมูลที่นำเข้าปัจจุบันมี 99 แห่งจากชุดข้อมูลทางการสองจังหวัด ห้ามใช้จำนวนนี้อ้างว่าครบทั่วประเทศ

- กรุงเทพมหานคร: 88 สน. จาก [ชุดข้อมูลสถานีตำรวจ กรุงเทพมหานคร](https://data.bangkok.go.th/dataset/2eeda85a-084c-462b-8686-24dbf85b9e03/resource/bf771314-9841-4a23-8bb4-5d0f7866fa41/download/police.csv)
- นนทบุรี: 11 สภ. จาก [ทะเบียนสถานีตำรวจในจังหวัดนนทบุรี](https://nonthaburi.gdcatalog.go.th/dataset/69-17-tour) เก็บแถวปีล่าสุดของแต่ละชื่อ รวม สภ.ปากเกร็ด ไม่รวมแถวซ้ำปี 2568/2569
- จังหวัด 77 รายการ: รายการจังหวัดใน API ของ Government Data Catalog โดยตัดรายการองค์กรส่วนกลางและรวมกรุงเทพมหานครจากชุดข้อมูล กทม.

นำเข้าด้วย `python3 scripts/police-registry/import-open-data.py` ไม่เพิ่มชื่อสถานีจากการคาดเดา เก็บ URL ผู้เผยแพร่และ SHA-256 ของ CSV ไว้ใน `src/data/police-stations.json` ทุกสถานีอ้างรหัสแหล่งข้อมูลได้ คำย่อ สน./สภ. เป็นชื่อค้นหาที่แปลงจากชื่อ/ประเภทในต้นทาง ชื่อเต็มเก็บตามต้นทาง รวมการสะกดที่คลาดเคลื่อนในข้อมูล กทม. สองแถว (จักรวรรดิ/เตาปูน) ไม่สร้างสถานีเพิ่มจากการแก้ชื่อ

ช่องค้นหาไม่เลือกสถานีเอง ไม่รับ DSI หรือชื่อหน่วยงานที่ผู้ใช้แต่งขึ้น จังหวัดที่ยังไม่มีข้อมูลแสดงว่ายังไม่ได้นำเข้าทะเบียน ข้อมูล DSI เดิมไม่ถูกแปลงเป็นสถานีตำรวจหรือเลือกให้เอง และประวัติหนังสือเดิมไม่ถูกลบ

ยังต้องมีทะเบียนหน่วยงานทางการล่าสุดครอบคลุม สน./สภ. ทั่วประเทศ พร้อมวันที่/ขอบเขตของทะเบียนและตัวตรวจจำนวนต่อจังหวัดก่อนเปลี่ยน `coverage` เป็นครบ การมีตัวเลือกจังหวัด 77 รายการไม่ได้หมายความว่ารายชื่อสถานีครบ 77 จังหวัด

แหล่งทะเบียนกลางที่ตรวจเมื่อ 8 ตุลาคม 2569:

- https://www.royalthaipolice.go.th/station.php ตอบ HTTP 403
- https://pdd.police.go.th/download/2559/02_Positionanalysis1/Conclusion59_3/allpolicestation.pdf ตอบ HTTP 403 และเป็นทะเบียนเก่าปี 2559
- https://itap.nacc.go.th/ และ https://itas.nacc.go.th/ ตอบ HTTP 403

ยังไม่ได้นำข้อมูลจากแหล่งที่เข้าไม่ได้มาอ้างเป็นทะเบียนครบ ไม่มีการเพิ่มรายการตัวอย่างแล้วอ้างว่าครบ
