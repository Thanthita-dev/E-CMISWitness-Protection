# สถานะฟังก์ชันของ Mockup ระบบคุ้มครองพยาน E-CMIS กิจกรรมที่ 6

อ้างอิงไฟล์ `index.html` ณ วันที่ 6 สิงหาคม 2569

## มีในม็อคอัพ

- ทะเบียนและการรับคำร้อง คบ.1/คบ.2
- หน้าแบบ คบ.1-17
- คิวเจ้าหน้าที่ ผู้บังคับบัญชาชั้นต้น ผอ.สำนัก/กอง และชุดคุ้มครอง
- การตีกลับ ขอเอกสารเพิ่ม และเก็บเหตุผล
- ทะเบียนรับผลกิจกรรมที่ 7 และตัวอย่างผลอนุมัติ/ไม่อนุมัติ
- งานหลังอนุมัติ คบ.8 คบ.9 คบ.11 และการเริ่มคุ้มครอง
- คบ.13 คบ.14 รายงานเหตุสำคัญ อุทธรณ์ รายงาน และ Notification ตัวอย่าง

## มีบางส่วนหรือเป็นข้อมูลจำลอง

- การถอนคำร้อง การยุติ และการส่งต่อภายนอก
- ลายมือชื่อ การอัปโหลดไฟล์ การส่งหนังสือ การแจ้งเตือน และการ Export
- การเชื่อมเลขคดีหลัก/เลขไต่สวนและการรับผลจากกิจกรรมที่ 7
- Audit Log ซึ่งยังผูกเฉพาะบาง Action หลังอนุมัติ

## ยังไม่มีระบบจริง

- Backend, Database และ File Storage
- API กับกิจกรรมที่ 5/กองบริหารคดีและกิจกรรมที่ 7
- e-Signature, 2FA, Encryption และ Field-level security จริง
- e-Saraban, Email, SMS, Push Notification และหลักฐานส่งมอบจากบริการจริง
- Audit Log ครบทุกการเปิดดู แก้ไข ส่งต่อ ดาวน์โหลด และลงนาม

## จุดที่ต้องแก้หรือถามลูกค้า

1. คบ.8 มีรายชื่อชุดคุ้มครองแล้ว หน้ามอบหมายไม่ควรเลือกทีมใหม่โดยไม่มีคำสั่งแก้ไข
2. ยืนยันแหล่งเลขไต่สวน ผู้สร้างเลข ผู้กรอก/เลือกเลข และข้อมูลที่ระบบต้นทางส่งกลับ
3. ยืนยันบทบาทเจ้าหน้าที่ทะเบียนกลาง กอท. และผู้รับผลกิจกรรมที่ 7
4. ยืนยันสิทธิ์และสายงานของเขต 1-9 กับ กปท.1-5
5. ยืนยันผู้จัดทำร่าง คบ.8 ก่อนเลขาธิการลงนาม
6. ยืนยันค่าการแจ้งเตือนก่อนครบกำหนด คบ.14
7. ทำ Workflow คบ.7, คบ.12, คบ.15, คบ.16 และ คบ.17 ให้ครบตั้งแต่รับข้อมูลจนปิดเรื่อง
8. ปรับชื่อแท็บชุดคุ้มครองที่ระบุ คบ.8 แต่มีรายการ คบ.5 อยู่ในแท็บเดียวกัน
